# Web-Scrape-From-Amazon
This project is a web scraper for extracting product data from Amazon using Selenium and Microsoft Edge WebDriver. It automates search queries, navigates multiple pages, and collects key details such as product descriptions, prices, ratings, review counts, and URLs. 

# Key Features:

Dynamic URL Generation: Enables automated searching for any given product keyword.
Headless Browser Execution: Ensures efficient and stealthy scraping.
Data Storage in CSV: Organizes extracted data for further analysis.
Randomized Delays: Mimics human behavior to reduce detection risk.
Scalable Design: Supports scraping up to 20 pages per search term.
This scraper facilitates market analysis, price monitoring, and competitive research, making it a valuable tool for e-commerce insights. 🚀
